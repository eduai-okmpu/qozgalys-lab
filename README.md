# ҚОЗҒАЛЫС — онлайн физика зертханасы

Интерактивті виртуалды физика зертханасы (7–11 сынып). Әр тәжірибеде анимация, дыбыс, өлшеу кестесі, автоматты график және нәтижені есептеу бар.

| № | Тәжірибе | Не өлшейміз |
|---|----------|-------------|
| 01 | Математикалық маятник | еркін түсу үдеуі g (Жер, Ай, Марс, Юпитер) |
| 02 | Бойль–Мариотт заңы | pV = const, изотермалар |
| 03 | Ом заңы | резисторлардың кедергісі R |
| 04 | Серіппелі маятник | серіппенің қатаңдығы k |
| 05 | Жинағыш линза | фокус аралығы F және оптикалық күш D |
| 06 | Фотоэффект | Планк тұрақтысы h және шығу жұмысы A |

Өлшемдерді CSV файл етіп жүктеуге болады. Сайт таза HTML/CSS/JavaScript-пен жазылған, ешқандай кітапхана мен құрастыру қажет емес — `index.html` файлын браузерде ашсаңыз жеткілікті.
